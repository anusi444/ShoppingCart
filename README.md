# 🛒 Shopping Cart Web Application

A dynamic and user-friendly **Shopping Cart system** built using Java technologies.
This project allows users to browse products, add items to cart, and manage purchases efficiently.

---

## 🚀 Features

🛍️ Browse available products
➕ Add items to cart
➖ Remove items from cart
🔄 Update product quantity
💰 Calculate total price automatically
🔐 Simple user session handling

---

## 🛠️ Tech Stack

* 💻 Java (JSP & Servlets)
* 🌐 HTML, CSS
* 🗄️ MySQL Database
* 🔗 JDBC / Hibernate
* ⚙️ Apache Tomcat Server

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/ShoppingCartt.git
```

2. Open in IntelliJ / Eclipse

3. Configure MySQL database

4. Update DB credentials in your configuration file

5. Run the project on Apache Tomcat
